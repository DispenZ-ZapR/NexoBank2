Актуальность проекта

  • Цифровая трансформация банковского сектора — банки переходят на цифровые платформы, требуются квалифицированные специалисты

  • Образовательная ценность — изучение полного цикла создания enterprise-приложения

Цели и задачи проекта

Цель:

Разработка функционального REST API банковской системы на Java с использованием Spring Boot

Задачи:

  • Спроектировать архитектуру приложения и базу данных
  • Реализовать систему аутентификации и авторизации (JWT)
  • Разработать функционал управления счетами и транзакций
  • Создать API документацию (Swagger UI)
  • Провести тестирование системы

Функциональные возможности

  • ✅ Регистрация и аутентификация — клиенты и сотрудники банка, JWT токены
  • ✅ Управление банковскими счетами — создание, блокировка, активация счетов
  • ✅ Денежные переводы — переводы между счетами с контролем баланса
  • ✅ Система заявок — обработка заявок на открытие счетов
  • ✅ История операций — отслеживание всех транзакций
  • ✅ Управление паспортными данными — хранение и валидация документов клиентов
  • ✅ Ролевая модель — разграничение прав доступа (CLIENT, EMPLOYEE)

Архитектура приложения

Многослойная архитектура:

  • Controller Layer — REST API endpoints, обработка HTTP запросов
  • Service Layer — бизнес-логика приложения
  • Repository Layer — взаимодействие с базой данных (Spring Data JPA)
  • Entity Layer — модели данных (JPA сущности)
  • DTO Layer — объекты передачи данных
  • Security Layer — JWT фильтры, аутентификация
  • Mapper Layer — маппинг между Entity и DTO (MapStruct)

Структура базы данных

Основные таблицы:

  • users — пользователи системы (клиенты и сотрудники)
  • clients — информация о клиентах банка
  • employees — информация о сотрудниках
  • passports — паспортные данные клиентов
  • accounts — банковские счета
  • account_requests — заявки на открытие счетов
  • operations — история финансовых операций
  • transfers — денежные переводы между счетами

Система безопасности

🔐 JWT Authentication

  • Токены доступа с ограниченным временем жизни
  • Хранение секретного ключа в переменных окружения
  • Автоматическая валидация токенов через Security Filter Chain

🛡️ Spring Security

  • Ролевая модель доступа (CLIENT, EMPLOYEE, ADMIN)
  • Защита endpoints по ролям
  • Хеширование паролей (BCrypt)

Важно: Все критичные операции требуют аутентификации и проверки прав доступа

Процесс разработки

Этапы реализации:

  • Проектирование БД — создание ER-диаграммы, нормализация таблиц
  • Миграции Flyway — версионирование схемы базы данных
  • Создание Entity классов — JPA аннотации, связи между таблицами
  • Разработка Repository слоя — Spring Data JPA
  • Реализация бизнес-логики — Service классы
  • Создание REST API — Controller классы
  • Настройка Security — JWT фильтры, конфигурация
  • Тестирование — ручное тестирование через Swagger UI
