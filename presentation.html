Система безопасности

Многоуровневая защита:

  • JWT Authentication: Токенная аутентификация без сохранения сессий
  • Password Hashing: Шифрование паролей с помощью BCrypt
  • Email Verification: Подтверждение email при регистрации
  • Role-Based Access Control: Разграничение прав доступа

Процесс аутентификации:

  1. Клиент регистрируется в системе
  2. На email отправляется ссылка для активации
  3. Клиент устанавливает пароль
  4. После входа выдается JWT токен (срок действия: 1 час)
  5. Токен используется для всех последующих запросов
